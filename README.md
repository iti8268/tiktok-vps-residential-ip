## AUD$8.9 的英德入门款，和“TikTok 专线”卖的是不同 IP

同叫英国、同叫德国，WePC 的产品线里存在两类播放环境。资料页里另外列过“英国 TikTok 专线”和“德国 TikTok 专线”，各 1 核 / 0.5GB / 10GB SSD / 1TB / 200Mbps，折算人民币约 ¥41.86/月，英国那款明确标注“原生**非家宽** IPv4”，德国那款标注“德国原生 IP”。而上表里的英国入门款写的是“原生家宽”，德国入门款是“TikTok 专用”，两者的 IP 属性并不相同。

这类差异在别的地区也有。新加坡 TikTok 专用 AUD$17.9 是原生 IPv4，新加坡家宽 TK 直播 AUD$24.9 才是家宽 IP，差 7 澳元；马来西亚 TikTok 专用 AUD$19.9 标的是“原生 IP / Hosting 非家宽”，双 ISP 家宽 AUD$24.9 才是住宅属性，差 5 澳元。

TikTok 会读取 IP 的数据库属性，数据中心 IP 在 Scamalytics、ipinfo 这类库里被标成“数据中心/代理”，住宅 IP 和双 ISP 则显示为普通家庭用户。这是圈内通行的解释，不是 TikTok 官方文档的结论，但足以解释为什么同一地区、配置接近的两个套餐会差出几澳元。预算紧可以买非家宽款做视频发布测试，直播和起号阶段建议直接上家宽或双 ISP。

## 常见问题

**512MB 内存够跑 TikTok 吗？**
够。发视频和推流主要吃带宽和线路稳定性，不靠本地算力。512MB 跑推流软件、浏览器后台会紧张，纯发布或挂机没问题；要同时开多个工具，选 1GB 内存的新加坡家宽或韩国节点更稳。

**官网是澳元，支付宝怎么付？**
结算时选支付宝，按实时汇率扣人民币。注册时把结算币种选成澳币，避免平台先转美元再转人民币，多一道汇损。

**优惠码在哪里填，为什么没打折？**
在购物车或结算页有优惠码输入框，填入后点应用再看总价变化。台湾、新加坡及美国家宽系列有资料提到不参与优惠码，输入后价格没变就是这个原因。

**热门款显示库存 0 怎么办？**
英国、德国的入门款经常断货。可以等补货，或者选配置接近的法国、西班牙款，也可以先买同地区另一档套餐过渡，别为了等一款把账号晾着。

**双 ISP 和普通原生 IP 有什么区别？**
双 ISP 指 IP 同时归属两家当地运营商，在 IP 库里显示为住宅用户的可信度更高；普通原生 IP 只是当地运营商分配、没被转手，属性仍是机房或 Hosting。两者价格差通常在 5–7 澳元/月。
